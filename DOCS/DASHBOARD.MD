# Dashboard Design

## Purpose
The dashboard provides a clear overview of treatment adherence without offering medical guidance.

## Key Indicators

### Adherence Percentage
- Calculated using only doses taken within the confirmation window.
- Late intakes do not count toward adherence.

### Daily Summary
- Taken on time
- Taken late
- Missed

### Treatment Progress
- Represents time-based progress, not medical effectiveness.

## Visual Principles
- Clear, non-judgmental language
- No recommendations or alerts based on performance
