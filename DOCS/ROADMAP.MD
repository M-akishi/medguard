# Roadmap

## v0.1 – Minimum Viable Product
- Create and manage medications
- Schedule time-based reminders
- Persistent alarms
- Secure dose confirmation (biometric or PIN)
- Local dose logging

## v0.2
- Weekly adherence dashboard
- Calendar view
- Export data to CSV
- Accessibility improvements

## v0.3
- Backup and restore (manual)
- Multi-language support
- UI/UX refinements
