# Architecture Overview

## Platform
- Android only

## Technology Stack
- Kotlin
- Jetpack Compose
- MVVM
- Room (SQLite)
- AlarmManager / Foreground Services
- Android BiometricPrompt API

## Core Principles
- Local-first
- No cloud dependency
- Explicit user confirmation
- Immutable historical data

## Non-Goals
- Medical recommendations
- Automatic dose adjustments
- Remote monitoring
