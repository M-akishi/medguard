# MedGuard

MedGuard is an open-source Android application designed to help users
remember and consciously confirm their daily medication intake.

The app focuses on time-based reminders, secure confirmation, and
clear treatment tracking — without relying on physical pill organizers.

## Features (planned)
- Time-based medication reminders
- Biometric or PIN-based dose confirmation
- Local-first data storage
- Treatment adherence dashboard
- No accounts, no tracking, no ads

## Philosophy
- Android only
- Open source
- Privacy-first
- No cloud by default

## Disclaimer
This application does not provide medical advice and does not replace
professional healthcare guidance.
